# 보드 단독 브링업 및 시리얼 통신 검증

완료: 2026-08-19

## 1. 목적

모터, 엔코더, micro-ROS 같은 복잡한 요소를 붙이기 전에 보드 단독으로 기초적인 하드웨어 동작을 검증

1. 클록 및 핀 검증: 84 MHz 클록이 정상 동작하고 PA5(LD2 초록 LED)가 제어되는가?
2. 시리얼 통신 한계 실측: 호스트(우분투 PC)와 통신할 때 ST-LINK VCP(가상 시리얼 포트)가 데이터 유실 없이 버티는 최대 속도는 얼마인가?

## 2. 왜 보드레이트 스윕을 했는가?

NUCLEO 보드는 메인 칩(STM32F446RE)과 PC 사이에 ST-LINK 디버거 칩이 중간 다리(USB-to-Serial) 역할을 한다.

* 이 경로에는 하드웨어 흐름제어(RTS/CTS) 선이 없다.
* 메인 칩이 데이터를 너무 빠르게 쏟아내면 중간의 ST-LINK 칩 내부 버퍼가 넘쳐서 데이터가 유실된다.
* 나중에 micro-ROS를 얹었을 때 통신이 끊기는 문제를 원천 차단하려면, 사전에 확정해야 한다.

## 3. 측정 방법

* MCU 동작: `hello <counter>\n` 문자열을 딜레이 없이 최고 속도로 연속 송출
* 호스트 검증: 스크립트로 번호가 중간에 비는지, 문자가 깨졌는지 검사
