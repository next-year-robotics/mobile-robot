# 엔코더 브링업 및 바퀴 틱 수 실측

완료: 2026-08-20

## 1. 목적

1. TIM2/TIM3 encoder mode가 잘 동작하는가?
2. 바퀴 1회전당 틱 수(`ticks_per_wheel_revolution`)는 실제로 얼마인가?

## 2. 구성

| 항목 | 값 |
|---|---|
| 모터 | JGB37-520 × 2 |
| 엔코더 | 홀 방식, 채널당 공칭 11 pulse/rev (모터축 기준) |
| 왼쪽 A/B | PA6 / PA7 — TIM3 encoder |
| 오른쪽 A/B | PA0 / PA1 — TIM2 encoder |
| Encoder Mode | TI1 and TI2 (×4 체배) |
| ARR | 65535 (두 타이머 모두 16-bit 범위로 통일) |
| 입력 필터 IC1F/IC2F | 4 |
| A/B 외부 풀업 | 10 kΩ → 3V3 (4개) |
| 엔코더 전원 | NUCLEO 3V3 실측 3.307 V |

## 3. 동작 검증

| 시험 | 기대값 | 실측 | 결과 |
|---|---|---|---|
| 정지 60초 자발 카운트 | 0 tick | 좌 0 / 우 0 | **PASS** |
| 왼쪽만 회전 시 오른쪽 변화 | 0 tick | 0 | **PASS** |
| 오른쪽만 회전 시 왼쪽 변화 | 0 tick | 0 | **PASS** |
| 왼쪽 정/역 1회전 복귀 | ±2 tick | 0 tick | **PASS** |
| 오른쪽 정/역 1회전 복귀 | ±2 tick | 1 tick | **PASS** |


전진 방향 원시 부호는 왼쪽 +, 오른쪽 - 


## 4. 바퀴 10회전 틱 수 실측

바퀴에 표시점을 두고 정확히 10회전시켜 누적 틱 차이를 잰다.

| 바퀴 | 방향 | 1 | 2 | 3 | 4 | 5 | 평균 tick/rev | 표준편차 | RSD |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 왼쪽 | 정방향 | 2473.9 | 2473.8 | 2476.2 | 2474.7 | 2475.8 | **2474.88** | 1.09 | **0.044 %** |
| 왼쪽 | 역방향 | 2482.0 | 2480.7 | 2475.3 | 2476.7 | 2475.9 | **2478.12** | 3.03 | **0.122 %** |
| 오른쪽 | 정방향 | 2473.7 | 2475.0 | 2473.1 | 2475.7 | 2474.3 | **2474.36** | 1.03 | **0.042 %** |
| 오른쪽 | 역방향 | 2475.6 | 2474.1 | 2475.5 | 2474.6 | 2473.6 | **2474.68** | 0.87 | **0.035 %** |

### 확정값

| 항목 | 값 |
|---|---|
| `ticks_per_wheel_revolution` 왼쪽 | **2476.5** |
| `ticks_per_wheel_revolution` 오른쪽 | **2474.5** |
| 좌우 통합 | **2475.5** |
